# Statement-of-applicability-style summary

This educational summary records inclusion, design status and evidence for RheinShield controls. It is deliberately not called a formal ISO Statement of Applicability and has not been approved by a certification body. Controls are included when they address scenario risk, law/framework expectations or secure Azure delivery. Any exclusion must cite an asset/risk decision, compensating control, owner and review date.

Implementation states distinguish fixture, plan, license, cost and live evidence. See `CONTROL_EVIDENCE_MATRIX.md` for 20 controls and `docs/evidence/CAPABILITY_MATRIX.md` for technical status.
