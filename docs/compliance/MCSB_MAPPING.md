# Microsoft Cloud Security Benchmark mapping

MCSB v1 remains the stable implementation baseline used by the control evidence matrix. Relevant families include Governance Strategy, Asset Management, Identity Management, Privileged Access, Network Security, Data Protection, Logging and Threat Detection, Incident Response, Posture/Vulnerability Management, DevOps Security and Backup/Recovery.

MCSB v2 preview material may inform future design but is not merged into the stable compliance crosswalk. Defender recommendations and regulatory-compliance views are evidence inputs, not certification. Source/stability decisions are documented in `docs/research/CURRENT_PLATFORM_DECISIONS.md`.
