# Access review evidence model

Quarterly reviews cover privileged groups, guest/supplier access, GitHub federated identities and resource owners. Each record contains review ID, population hash, reviewer, start/end time, decision, justification, removal evidence and exceptions. Default is deny/remove when the reviewer does not respond. Auto-apply remains disabled in the template until the organization validates dependencies.
