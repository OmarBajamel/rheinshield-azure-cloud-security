# Security controls

RheinShield connects preventive policy and identity controls to detective Sentinel rules and corrective runbooks. The versioned policy baseline contains 14 controls; the cross-framework evidence catalog contains 20 controls. Machine-readable sources are `infra/policies/controls.json` and `artifacts/evidence/control-evidence-matrix.json`. Detailed intent, exceptions, remediation, and framework mapping are in `POLICY_BASELINE.md` and the compliance documents.
