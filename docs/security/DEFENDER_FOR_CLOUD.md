# Defender for Cloud

Status: `READY_LICENSE_REQUIRED` for paid plans; `READY_NOT_AUTHENTICATED` for live posture. The design starts with Foundational CSPM, exports recommendation severity, affected type, owner, remediation, due date, and status, and maps stable Microsoft Cloud Security Benchmark v1 controls. MCSB v2 preview is kept separate. No paid plan, secure score, or certification is claimed.

Activation is manual and cost-gated. It must record the plan changed, activation time, test scope, and reversal. `artifacts/evidence/defender-status.json` is authoritative.
