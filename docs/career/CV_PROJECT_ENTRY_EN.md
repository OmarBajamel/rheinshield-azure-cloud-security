# CV project entry — English

**RheinShield — Azure Cloud Security & Microsoft Sentinel Portfolio**  
Designed an evidence-first Azure landing-zone and security-operations case study combining Terraform, Zero Trust identity, detection engineering, incident response, and German NIS2/ISO/BSI mapping with an accessible bilingual public demo.

- Built and provider-validated five reusable Terraform modules plus an Azure Verified Modules enterprise reference and a 14-control policy baseline, with an explicit €20 cost/teardown gate.
- Engineered and fixture-tested 14 Sentinel analytics rules against 738 deterministic events; structurally validated five hunts, three workbooks, three automation rules, and three disabled dry-run playbooks.
- Produced 27 traceable risks, 20 evidence controls, a complete INC-001 exercise, automated sanitization, and an eight-page English/German dashboard with zero axe A/AA violations across three representative scans.

**Technology:** Azure · Terraform 1.16 · Azure Verified Modules · Entra ID · Zero Trust · Microsoft Sentinel · KQL · Bicep · MITRE ATT&CK · FastAPI · React/TypeScript · GitHub Actions/OIDC · NIS2/BSIG · ISO 27001 · BSI IT-Grundschutz · MCSB
