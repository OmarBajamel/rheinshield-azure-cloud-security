# CV-Projekteintrag — Deutsch

**RheinShield — Azure Cloud Security & Microsoft Sentinel Portfolio**  
Konzeption und Umsetzung einer nachweisorientierten Azure Landing Zone mit Zero-Trust-Identitäten, Detection Engineering, Incident Response und NIS2-/ISO-/BSI-Zuordnung; dokumentiert in einer barrierearmen zweisprachigen Live-Demo.

- Fünf wiederverwendbare Terraform-Module, eine Enterprise-Referenz mit Azure Verified Modules und eine 14-teilige Policy-Baseline mit klarer Kosten- und Löschleitplanke erstellt und gegen aktuelle Provider validiert.
- 14 Sentinel Analytics Rules an 738 deterministischen Ereignissen fixture-getestet; fünf Hunting Queries, drei Workbooks, drei Automation Rules und drei deaktivierte Dry-Run-Playbooks strukturell validiert.
- 27 Risiken und 20 Evidenzkontrollen, die vollständige Übung INC-001, automatisierte Sanitisierung sowie acht englische/deutsche Dashboard-Seiten mit null axe-A/AA-Verstößen in drei repräsentativen Prüfungen umgesetzt.

**Technologien:** Azure · Terraform 1.16 · Azure Verified Modules · Entra ID · Zero Trust · Microsoft Sentinel · KQL · Bicep · MITRE ATT&CK · FastAPI · React/TypeScript · GitHub Actions/OIDC · NIS2/BSIG · ISO 27001 · BSI IT-Grundschutz · MCSB
