# Project summary

RheinShield is an offline-first Azure cloud-security portfolio for German junior cloud-security, Sentinel/SOC, IAM, DevSecOps, and GRC consulting roles. It demonstrates architecture, code, tests, incident reasoning, assurance traceability, and bilingual stakeholder communication while keeping live/cloud limitations explicit.

Live demo: https://omarbajamel.github.io/rheinshield-azure-cloud-security/
