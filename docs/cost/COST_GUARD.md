# Azure cost guard

Maximum incremental spend for the entire project run is `RHEINSHIELD_MAX_INCREMENTAL_COST_EUR=20`. No apply may proceed without authenticated context, an allowlisted sandbox subscription, exact suffix-bound resource groups, an Infracost JSON estimate in EUR, and an expiry no more than 24 hours away. `deploy-lab.*` creates a saved Terraform plan, produces the raw estimate, and calls `tools/cost-gate/attest.py` plus `verify.py`; the one-hour attestation must match both the raw-source hash and exact plan hash and remain positive and no greater than EUR 20. A typed number is never accepted as cost evidence. Tags are Project=RheinShield, Owner=OmarBaJamel, Environment=Lab, DataClassification=Synthetic, ManagedBy=Codex, and ExpiresAt.

Azure Firewall, Bastion, DDoS Network Protection, NAT Gateway, VM/AKS fleets, paid Defender plans, and high-volume Sentinel ingestion are excluded. Synthetic ingestion must remain below 100 MB. If estimation is unavailable, deployment is blocked while offline validation continues.

Teardown is a retained-provenance, two-step local operation. The first call writes a 15-minute plan containing the subscription and three exact names; the execute call revalidates ownership, synchronously removes those groups, verifies absence, and deletes/verifies the exact app registration, service principal, and federated credential recorded by bootstrap. The GitHub OIDC workflow is intentionally plan-only so an ephemeral runner cannot strand lifecycle state. Key Vault purge protection can leave a soft-deleted, name-reserving object for seven days; this is a documented residual rather than an active resource.
