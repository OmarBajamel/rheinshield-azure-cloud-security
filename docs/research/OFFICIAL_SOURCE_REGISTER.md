## Evidence quality and caveats

- The Terraform Registry version APIs were queried on 2026-08-29. They returned `Azure/avm-ptn-alz/azurerm 0.21.0`, `Azure/azapi 2.12.0`, `hashicorp/azurerm 5.3.0`, and `hashicorp/azuread 3.9.0` as the highest non-prerelease semantic versions.
- The Sentinel API-version page's displayed `Last updated` metadata predates some versions listed on the generated page. The version table itself explicitly labels `2025-09-01` as current GA; that label, not the stale page metadata, drives the decision.
- Product documentation can describe technical availability without proving that the current tenant owns the required entitlement. Any live validation must query the tenant/subscription and use the repository status model.
- Microsoft and GitHub documentation is operational guidance, not legal advice. Control-framework mappings do not establish NIS2, ISO 27001, or regulatory compliance.
